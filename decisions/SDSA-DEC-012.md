# Decision Record: Full-Site, Two-Pathway Rebuild Scope

**Decision ID:** `SDSA-DEC-012`
**Recorded:** 2026-09-17
**Status:** `CANONICAL_SCOPE_WITH_CONTENT_RECONCILIATION_PENDING`

## Decision

The named launch target is a full-site redesign, not a homepage-only redesign. The homepage is the primary class-enrollment entry point, while the rebuilt nonprofit site must also preserve or improve Programs, Private Training, Coaches, About, FAQ, Get Involved, and Contact as distinct, accessible destinations.

The website has two primary user pathways:

1. Group-training families learn about the current park-district classes and complete registration on the City of Chula Vista website.
2. Private-training families review verified coach profiles, choose a preferred coach, and submit an inquiry routed according to that choice.

The Replit reference is the principal experience source for the private-training model. The current public website is the principal source for the broader organizational content inventory. Neither source independently proves that time-sensitive program information, coach details, routing destinations, support links, or quantitative claims are current.

## Consequences

- `SDSA-LAUNCH-v1` must be revised before it can be approved.
- The existing one-page prototype remains evidence, not the canonical build target.
- Coach roster, coach profile facts, inquiry routing destinations, fallback routing, and support/donation destinations must be reconciled before a Build Assignment is issued.
- This decision does not grant implementation, deployment, ad-publication, or spending authority.
